# SNS体験サイト ― あなたの投稿は大丈夫？SNS投稿チェック！

X（旧Twitter）に似た画面で投稿を読み解き、SNSを安全に利用するための判断力を学ぶ、体験型の情報リテラシー教材です。架空の中学生「KTさん」の投稿やプロフィール、画像・動画、フォロー関係を手がかりに、全8問に取り組みます。

主に小学6年生を対象とし、授業やワークショップでの情報モラル学習、家庭での話し合い、自主学習での利用を想定しています。ブラウザーで動作する静的Webアプリで、ログインやSNSアカウントの登録は必要ありません。

## 制作の目的

何気ない投稿でも、複数の情報を組み合わせることで、誕生日や所属先、生活圏などが推測されることがあります。また、画像や動画があるからといって、その情報が事実とは限りません。根拠のないうわさや攻撃的な言葉の発信は、相手を傷つけ、発信者自身の責任にもつながります。

本教材は、こうしたSNSのリスクを「注意事項として読む」だけでなく、投稿から自分で気づき、考える体験として学べるように制作しました。「どの情報が手がかりになったか」「発信する前に何を確かめるべきか」を考え、日常のSNS利用に生かすことを目指しています。

個人情報を推測する設問は、自分の情報を守るための気づきを得るためのものです。実在する人の個人情報を探したり、公開したりすることを目的としていません。

## 学べる内容

14件の投稿と全8問を通して、次の3つのテーマを扱います。正解そのものは、アプリ内で回答した後に確認できます。

| テーマ | 問題 | 学習のポイント |
| --- | --- | --- |
| 個人情報 | 1. 誕生日／2. 所属クラブ／3. 所属中学校／4. 個人情報漏洩のリスク | 投稿・ユーザーID・フォロー関係・写真などから、どのような情報が知られてしまうかを考える |
| 偽情報 | 5. 生成AI画像／6. 偽情報発信のリスク | 画像や動画をうのみにせず、発信源や根拠を確かめること、誤った情報を広める影響を考える |
| 誹謗中傷 | 7. 根拠のない悪口／8. 誹謗中傷発信のリスク | 意見と攻撃の違いや、根拠のない発信が相手や社会に与える影響を考える |

## 体験の流れ

1. KTさんのプロフィールや投稿を読み、写真・動画やフォロー一覧も確認します。
2. 問題のタイトルボックスをクリック・タップすると、問題と回答欄がポップアップで開きます。
3. 必要に応じてヒントを開き、選択肢を選んで回答します。複数の回答を選ぶ問題もあります。
4. 問題ごとに正誤を確認します。不正解の場合は投稿を見直して再挑戦でき、正解後は解説を読めます。
5. 全8問に正解すると、完了メッセージと合計挑戦回数が表示されます。

授業などでは、解答後に「何を根拠に判断したか」「自分ならどのような投稿に変えるか」を話し合うことで、学びを振り返れます。

## 主な機能

- **投稿と問題を1画面に集約**：PCでは投稿と学習エリアを左右に配置し、それぞれ独立してスクロールできます。
- **スマートフォン対応**：縦長画面では問題ボックスを上部に2列×4行で固定し、その下で投稿を確認できます。
- **画像・動画による学習**：投稿画像の拡大表示、複数画像の切り替え、動画再生に対応しています。
- **ヒントと解説**：各問に開閉できるヒントを用意し、正解後に解説を表示します。
- **進捗の自動保存**：正解した問題と挑戦回数をブラウザーのlocalStorageに保存し、再読み込み後も続きから取り組めます。
- **読みやすさへの配慮**：漢字へのふりがな表示、問題ポップアップのキーボード操作、動きを減らす設定への対応を取り入れています。

## 動作確認方法

ビルド済みのサイトを `preview/` に収録しています。リポジトリを取得し、HTTPサーバーでこのフォルダーを配信すると確認できます。Python 3を利用する場合の例です。

```sh
git clone https://github.com/razy6174/sns-literacy-app8-24.git
cd sns-literacy-app8-24
python -m http.server 8000 --bind 127.0.0.1 --directory preview
```

ブラウザーで [http://127.0.0.1:8000/#/feed](http://127.0.0.1:8000/#/feed) を開いてください。サーバーはターミナルで `Ctrl+C` を押すと停止できます。Python以外の静的HTTPサーバーでも確認できます。

`index.html` をエクスプローラーから直接開く方法では、ブラウザーの制限によりJavaScriptが読み込まれない場合があるため、HTTPサーバー経由で確認してください。

静的サイトとして設置する場合は、`preview/` 内の `index.html` と `assets/` を同じ階層に配置します。ヘッダーのクマアイコンは設置元のゲーム一覧（`../index.html`）に戻るリンクのため、このリポジトリ単体で動かす場合、その移動先は含まれていません。

## 実装とファイル構成

Reactによる画面描画とハッシュ形式のルーティングを使い、HTML・CSS・JavaScript・画像・動画・フォントを静的ファイルとして配信します。アプリ専用のバックエンドやデータベースは使用していません。

| ファイル・フォルダー | 内容 |
| --- | --- |
| `preview/` | そのまま配信できるビルド済みサイト |
| `app-runtime.js` | プロフィール、投稿、問題・選択肢・解説、画面描画、採点、進捗保存 |
| `base.css` / `changes.css` | 基本スタイルと追加・調整したレイアウトや装飾 |
| `vendor-prefix.js` | Reactなどのライブラリを含む配信用コード |
| `media/` | 投稿画像・動画などの素材 |
| `media-manifest.json` | 素材と投稿・表示順の対応情報 |
| `build.cjs` / `build-manifest.json` | 配信用ファイルを生成する処理と出力ファイル一覧 |
| `verify*.cjs` / `check-furigana.cjs` | 開発時の変更内容やふりがなの確認用スクリプト |

### 編集・再ビルドについて

現在の編集用JavaScriptは、配信済みコードからアプリ部分を取り出して整形したものです。元のTypeScript／TSXプロジェクトではありません。`preview/index.html` は画面を起動する入口で、投稿文や問題文は `app-runtime.js` に記述されています。

**現状のビルド・検証スクリプトには、開発環境に依存する参照が残っています。** `build.cjs` は別フォルダーのTypeScript、リポジトリ外の素材フォルダー、同梱されていない `baseline/index.html` を参照します。一部の検証スクリプトも過去のバックアップを必要とするため、クローン直後にそのまま再ビルド・検証できる構成ではありません。再ビルドする場合は、依存関係と参照先の整備が必要です。ビルド済み `preview/` の閲覧には、これらの準備は不要です。

## 利用時の補足

- 登場するKTさんのアカウントと投稿は学習用に構成したものです。実在する公園などの写真や地名も教材に含まれます。Xの公式サービスではなく、実際のSNSへの投稿・共有や、利用者同士の交流機能はありません。
- 進捗は同じブラウザー・同じ配信元でのみ保持されます。別の端末やブラウザーへの同期はなく、ブラウザーの保存データを削除すると進捗も失われます。学習履歴をサーバーへ送信する機能はありません。
- 地図を使うヒントにはGoogleマップへの外部リンクがあります。リンク先の利用にはインターネット接続が必要です。
- 問題や正解データはブラウザーに配信されるJavaScript内に含まれます。学習・体験用の教材であり、正解データを秘匿する試験システムではありません。
